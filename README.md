# World Xplore

A multi-page website for a fictional travel agency. It promotes tour packages and cruises and has a contact form for enquiries.

Built with HTML and CSS as a diploma project at Republic Polytechnic.

**Live site:** https://hui0w0.github.io/World-Xplore/L03/Index.html

## Pages

- **Home** (`L03/Index.html`): a hero banner and featured deals, such as a Europe trip promotion, a Switzerland tour package and a 3-day, 2-night cruise.
- **Cruises** (`L03/Cruises.html`): cards for four cruise lines (Royal Caribbean, Costa, Princess and Norwegian), each with a short description and a "View More" link.
- **Contact Us** (`L03/ContactUs.html`): an enquiry form for name, email, phone and message, next to the agency's contact details.

Every page shares the same navigation bar (Home, Package Tours, Cruises, Contact Us) and footer.

## Highlights

- **A custom World Xplore logo**, drawn as inline SVG.
- **CSS animations:** the pages use keyframe animations for movement.
- **Separate stylesheets:** each page has its own stylesheet, built on a shared base style.

## Built with

HTML, CSS (keyframe animations) and inline SVG.

## Run it

View it at https://hui0w0.github.io/World-Xplore/L03/Index.html, or clone the repo and open `L03/Index.html` in a browser. No build step is needed.

```
git clone https://github.com/hui0w0/World-Xplore.git
```
